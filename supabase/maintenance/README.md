# 維運腳本

跟 `../migrations/` 不一樣：那邊是「系統結構的變更」，每一份都要跑過一次；
這邊是「偶爾才需要手動跑一次」的維護動作，平常不用管。

執行方式都一樣：到 Supabase 主控台 → SQL Editor → 貼上整份 → Run。

| 檔案 | 用途 |
| --- | --- |
| `reset_test_data_preview.sql` | **先跑這個。** 唯讀，只列出「會刪什麼、會留什麼」的筆數，不會改到任何資料。 |
| `reset_test_data.sql` | 正式上線前把測試期間 key 的資料清乾淨：刪請假單與考核作答、清掉個人假期額度的手動調整（回到比照勞基法），考核參與者「人留著、狀態歸零」。**不會**動到員工帳號、登入密碼、附件檔案，以及考核週期、假別、全公司預設額度、簽核流程等設定。 |

兩份都可以重複執行，跑第二次不會出錯。
